# Мехпрогресс — редизайн mechprogress.by

Прототип нового дизайна сайта ООО «Мехпрогресс» (запчасти для бульдозеров и экскаваторов, Минск).

- Демо: https://kirioa.github.io/mechprogress-redesign/
- Одна страница `index.html`, без сборки. GSAP 3.13 + Lenis лежат в `vendor/` (без CDN).
- Формы шлют на `send.mail.php` с теми же полями, что и старый сайт. Скрипт есть только на mechprogress.by: на демо-хосте форма показывает «Спасибо» и ничего не отправляет.
- Яндекс.Метрика 90633169 включается только на домене mechprogress.by.
